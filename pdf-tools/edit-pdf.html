Annotate PDF Drawings Without Uploading Them

Reviewing a supplier drawing, redlining a procedure, or marking inspection results usually means either printing the PDF or uploading it to some online editor. Both are wrong for controlled documents. This editor loads the PDF in your browser, lets you draw the markup on top, and then flattens your annotations permanently into a new PDF — locally. The file never crosses the network, so NDA drawings and customer data stay where they belong.

Built for drawing reviews and inspection

  • Redline reviews: box or circle a dimension, add an arrow and a note — the classic markup loop for ECNs and supplier corrections.
  • Inspection marking: drop green check marks on passed characteristics and red crosses on failures, straight onto the ballooned drawing.
  • Procedure edits: highlight steps, strike through obsolete lines with the pen, and note replacements in text.
  • RFQ clarifications: mark the features you want quoted differently before sending the drawing back to the vendor.

How it works

  1. Drop a PDF above — the first page renders immediately.
  2. Pick a tool: text, box, cloud, arrow, line, pen, highlighter, check or cross — plus a colour and size.
  3. Draw directly on the page; use Undo or Clear page to fix mistakes; page arrows move through the document.
  4. Click Download annotated PDF — your markup is flattened into the file, so it shows in every viewer and survives printing.

What this editor does not do

It does not rewrite existing PDF text — that is a re-authoring problem no browser tool does reliably, and pretending otherwise corrupts drawings. Markup is added on top of the original content, the same way a reviewer's red pen works. Text notes use the standard Helvetica character set (Latin letters, numbers, common symbols).
